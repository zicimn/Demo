品牌素材放置说明
================

把文件放到本目录（frontend/public/brand/）后，前端会自动使用，无需改代码。
所有文件名一律使用小写 ASCII —— 中文文件名在 git 与 URL 编码上都容易出问题，
也不利于他人 clone 后在不同系统上复现。

一、已接线的素材
----------------
1) logo.svg
   · 用途：顶部导航左上角的品牌标记
   · 现状：已内置一枚（渐变圆角 + 折线 A）
   · 替换方式：直接覆盖同名文件；若是其它格式，改 app/layouts/default.vue 里的 logoSrc

2) providers/<provider_code>.webp
   · 用途：首页供应商卡片与首屏预览卡的头像
   · 规格：正方形、圆形透明通道、256 × 256、WebP（质量 90）
   · 现状：deepseek.webp、qwen.webp 已就位；moonshot 暂无，自动回退为首字母头像
   · 回退链：本地头像 → 接口 ico 字段 → 首字母文字头像

   ⚠️ 新增头像时必须同步登记：
      打开 app/utils/providerAvatars.ts，在 PROVIDER_AVATARS 里加一行
      deepseek: '/brand/providers/deepseek.webp',
      不登记则不会生效（这是为了避免文件缺失时产生 404 请求）。

二、图片规格与体积要求
----------------------
· 单张控制在 30 KB 以内，全部头像合计不超过 150 KB。
· 尺寸 256 × 256 已足够：卡片展示 72px、预览卡 44px，256 覆盖 3 倍以上视网膜屏。
· 优先 WebP：同等画质下约为 PNG 的 1/6。若必须用 PNG，请先压缩。
· 圆形头像请直接导出带透明通道的圆形图，不要导出「黑底 + 白圈」的方形图，
  否则在圆形裁切下会露出黑边。

三、后续可接入的素材（放好后告知，由前端接线）
----------------------------------------------
· og-cover.png   分享卡片封面，1200 × 630，建议 < 200 KB
· hero-bg.jpg    首页 Hero 背景图，1600 × 600，会被压暗后叠加在渐变之上
· model/<model_slug>.webp   模型配图，规格同上
· empty-state.svg 空数据插画

四、关于版权与公开仓库
----------------------
本目录下的图片会随仓库一起公开（public/ 会被打包进构建产物）。
若图片由 AI 生成或来自第三方，请确认授权范围后再推送到公开仓库；
带生成工具水印的图建议先去除水印或获取授权，避免后续争议。
